# Changelog

## 1.1.1

- Добавлен локальный semantic vision слой SigLIP для визуально-смыслового сравнения миниатюр.
- Эталонные фотографии получают нормализованные 768-мерные embeddings и сохраняются локально.
- Инференс выполняется в отдельном Worker; при отсутствии модели сохраняется работа классического каскада.
- Добавлены настройки `checkSemanticImage` и `semanticThreshold`.
- Уточнена проверка `Not interested`, текстовый matcher и комбинированный dHash/pHash matcher.


Все значимые изменения проекта описаны здесь. Формат — [Keep a Changelog](https://keepachangelog.com/),
версионирование — [Semantic Versioning](https://semver.org/).

## [1.1.0] — 2026-10-04

Слияние улучшений из внешнего аудита (с сохранением ранее сделанных фиксов).

### Добавлено
- Обработка карточек в зоне прокрутки через `IntersectionObserver` (rootMargin-предзагрузка) вместо сканирования всего DOM.
- Жизненный цикл миниатюры: реальная превью дожидается загрузки (`waitForImage`), ключ повторной обработки учитывает URL картинки.
- LRU-кэш визуальных дескрипторов миниатюр (повторный расчёт одной и той же URL не выполняется).
- Сериализация действий YouTube через единую очередь (несколько карточек больше не открывают меню одновременно).
- `pHash` (DCT) как второй визуальный дескриптор поверх быстрого `dHash`; образец хранит оба.
- Раздельная статистика: `dismissedCount` (штатные сигналы YouTube) и `hiddenCount` (локальные скрытия); бейдж = сумма.
- Сопоставление по имени канала (наряду с заголовком).
- Поля Whisper в попапе: язык речи, путь модели, длительность анализа.
- Модульный тест `tests/test-matcher.js`.

### Изменено
- Текстовый матчер: убрано слепое `includes()`; сопоставление по токенам и границам слов, короткие слова совпадают только целиком, нечёткость — с ограниченным расстоянием Левенштейна (меньше ложных срабатываний).
- Проверка результата строже: фиксируется состояние snackbar ДО клика и засчитывается только новый `Undo`/снэкбар/исчезновение карточки.
- Whisper-модель по умолчанию приведена к multilingual `models/ggml-base.bin` (согласовано с `content.js` и `setup.sh`).

### Исправлено
- Убран опасный fallback «нажать первый пункт меню»: если однозначный пункт «Не интересно» не найден — ничего случайного не выбирается, выполняется только локальное скрытие.

## [1.0.2] — 2026-10-04

### Исправлено
- Критический баг: `clickDismissConfirm()` мог нажать snackbar «Отменить/Undo» и откатить только что отправленный сигнал. Подтверждение ищется только внутри реально открытого диалога, Undo никогда не нажимается.
- Режим «только изображения» не запускал сканирование (`hasDetectionTargets()` учитывал лишь ключевые слова).
- Выбор языков OCR фактически не применялся (параметр `langs` не доходил до инициализации воркера; добавлено пересоздание воркера при смене языка).

### Добавлено
- Извлечение и сопоставление имени канала.
