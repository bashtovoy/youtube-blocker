Импорт списка слов

Выберите JSON-файл — список заменит текущий и сразу применится во всех вкладках YouTube.

  • Подходит файл «Экспорт JSON» из этого расширения.
  • Формат { "keywords": ["война", …] } или просто массив ["война", …].
  • Элементы могут быть строками или объектами { "text": "…", "enabled": true }.
