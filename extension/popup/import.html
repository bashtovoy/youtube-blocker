Wortliste importieren

Wähle eine JSON-Datei — die Liste ersetzt die aktuelle und wird sofort in allen YouTube-Tabs übernommen.

  • Geeignet ist die Datei „JSON exportieren“ aus dieser Erweiterung.
  • Format { "keywords": ["krieg", …] } oder einfach ein Array ["krieg", …].
  • Einträge dürfen Strings oder Objekte sein: { "text": "…", "enabled": true, "exceptions": ["…"] }.
  • Das Feld exceptions bleibt erhalten; ältere Dateien funktionieren weiter. Das frühere Feld allowAll wird ignoriert.
